Система обміну повідомленнями

На цій сторінці можна ввести ім’я та повідомлення. Після натискання кнопки дані передаються на сервер для обробки та збереження в базі даних MongoDB.

Можливості сервісу

  • Передача повідомлень
  • Обробка даних через Socket
  • Збереження в MongoDB
  • Робота в режимі реального часу
